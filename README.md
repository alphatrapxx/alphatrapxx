## Hello, I'm alphatrapxx 👋

I write systems software in Rust and C, mostly things that live in the terminal and talk directly to Linux. I'm drawn to the kind of work where you end up reading man pages at 2 AM and wondering why a syscall behaves the way it does. Lately I've been pulling WebAssembly into that world too, curious about where the boundary between "system" and "portable" actually sits.

---

#### What I do

- 🔭 a lightweight Rust CLI toolkit for profiling and poking at Linux internals
- happier in a terminal than in an IDE
- usually building small tools nobody asked for
- currently deep in performance tuning
